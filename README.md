# TNM paso a paso

Seminario de estadificación TNM para estudiantes de 4.º de Medicina (Patología Quirúrgica I, UCM): historia del TNM, sus reglas y ocho casos de cáncer gástrico y de colon con preguntas interactivas.

Abrir: https://lozanon57.github.io/seminario-tnm/

Clasificación AJCC 8.ª edición (2017), igual a la UICC 9.ª para estómago y colon. Las respuestas se guardan solo en el navegador de cada alumno; no hay servidor ni registro.

Pruebas: `node --test tests/estadios.test.mjs tests/contenido.test.mjs`
